
A persistent top navigation bar allows users to on the slide:
- Return to the dashboard
- Preview their presentation
- Access key actions (delete, view slides)

The interface is divided into clear functional areas:
- Toolbar (actions)
- Canvas (slide content)
- Modals allow user to enter more input
- Editing options are only shown when an element is selected each customised for different elements.

- Required fields ensure necessary data is provided
- Width/height inputs are restricted using min/max values
- Empty submissions (e.g. video URL, code input) are prevented
